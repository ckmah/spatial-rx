# spatial-rx docs

Interactive notebook widgets for spatial omics. Python owns analysis; the
browser owns presentation; state syncs through typed traitlets.

## Start here

1. [Install](install.md) — `pip install spatial-rx`
2. [LandmarksWidget](landmarks.md) — draw on tissue coordinates
3. [GalleryWidget](gallery.md) — compact selectable cards

## Try a demo

- [LandmarksWidget on molab](https://molab.marimo.io/github/ckmah/spatial-rx/blob/main/demos/landmarks.py)
- [GalleryWidget on molab](https://molab.marimo.io/github/ckmah/spatial-rx/blob/main/demos/gallery.py)
